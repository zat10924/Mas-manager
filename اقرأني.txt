1) نزّل وثبّت Node.js (نسخة LTS) من https://nodejs.org
2) اضغط مرتين على build.bat وانتظر (أول مرة بتاخد كام دقيقة)
3) في مجلد dist هتلاقي:
   - "إدارة الأقسام Setup 1.0.0.exe"  => ملف تثبيت (بيعمل اختصار على سطح المكتب)
   - "إدارة الأقسام 1.0.0.exe"        => نسخة محمولة بدون تثبيت
للتجربة قبل البناء: npm install ثم npm start
